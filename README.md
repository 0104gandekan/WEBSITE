# RT 01 RW 04 Dusun 2 Pegandekan

Prototype UI portal digital warga sesuai mockup: Beranda, Profil, Informasi, Kegiatan, Layanan, Komunitas, Pengumuman, Galeri, Kontak, Login, Story 24h, Aspirasi, Diskusi, Polling, reaksi, komentar, PWA.

## Jalankan
npm install
npm run dev

Logo sementara ada di public/logo.svg. Ganti dengan logo asli yang dipakai pada mockup bila sudah tersedia.

## Tahap berikutnya
Integrasikan Supabase Auth/Database/Storage/Realtime, middleware role, upload media, notifikasi, moderasi, dan deployment Cloudflare Workers.
